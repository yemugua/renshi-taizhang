# 人事台账

只在本机运行的人事记录软件。装完就能用，不联网、不注册、不需要账号，数据就是本机一个 SQLite 文件，拷走就是备份。

适合几个人到几十人、几家公司合在一起管的小团队。

## 它解决什么

小公司的人事信息常散在 Excel、微信和纸质档案里：合同哪天到期靠人记，试用期转正靠 HR 自己盯，工资发没发过要翻聊天记录，员工离职时门禁卡、电脑、账号有没有收回全靠口头交接。

人事台账把这些固定成一张张表：

- **公司 / 部门**：一套软件管多家公司，员工挂在具体公司下，可再分部门
- **员工档案**：姓名、岗位、手机、入职、试用期结束、离职、备注
- **合同 / 证照**：合同起止日期、证件名称与到期日
- **入离职清单**：入职 6 项、离职 6 项默认清单，可自己增删勾选
- **考勤**：按天登记出勤 / 请假 / 病假 / 加班 / 缺勤，自动汇到当月
- **工资台账**：只记每月应发、实发和备注，不替你算个税和社保
- **提醒**：合同到期、试用期结束、证照到期，今天前后 30 天内的事项集中列出

## 五个页签

| 页签 | 干什么 |
|---|---|
| 员工 | 花名册，按公司筛选、按关键词搜；新建、编辑、离职、复职；点「档案」维护合同和证照；点「清单」走入离职手续 |
| 提醒 | 合同 / 试用期 / 证照到期，按剩余天数排序；过期会标红，点一行能直接打开员工档案 |
| 考勤 | 上半部分是当月每人出勤汇总，下半部分是逐条明细；可登记、可删除 |
| 工资 | 一个月一张表，直接填应发、实发、备注，底部实时合计；「保存本月」后才写库 |
| 设置 | 公司的新建、改名、停用；部门的新建、改名、停用 |

顶栏的「全部公司」筛选贯穿五个页签。停用的公司和部门不再出现在下拉里，但历史数据都保留。

## 几个约定

- **不做工资计算**：这里只是台账，记你实际发出去的数，避免和财务口径打架。
- **离职不是删除**：把状态改成离职、填上离职日期，人从默认花名册里隐藏，勾「显示离职」还能看到，也可以一键复职。
- **提醒有边界**：只显示今天前后各 30 天。很久以前就该处理却没处理的旧事项不再反复打扰；真要找，去员工档案里看。
- **清单每人一套**：第一次打开某个员工的清单时自动种入默认项，之后勾选、加项、删项都只影响这个人。
- **考勤按「天」记数量**：默认 1，也可以记 0.5 天或 3 小时，统计时直接累加。
